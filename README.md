# 🐶 Animais Caninos - Projeto Origamid

Projeto desenvolvido durante os estudos da plataforma Origamid.

---

## 📚 Sobre o projeto

O **Animais Caninos** é uma aplicação desenvolvida para praticar conceitos modernos do React, organização de componentes e consumo de funcionalidades da aplicação de forma dinâmica.

Durante o desenvolvimento deste projeto, foram trabalhados conceitos importantes como:

* ⚛️ Componentização
* 🧠 React Hooks
* 🔄 Gerenciamento de estado
* 🌐 Rotas
* 📡 Consumo de APIs
* 🎨 Estilização
* 📱 Responsividade
* 🚀 Boas práticas no React

---

## 🛠️ Tecnologias utilizadas

* ⚛️ React
* 🟨 JavaScript
* 🌐 HTML5
* 🎨 CSS3

---

## 📂 Funcionalidades

✨ Cadastro e login de usuários

🐕 Visualização de animais

📸 Upload de fotos

💬 Interações na aplicação

📱 Layout responsivo


---

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de:

* Melhorar habilidades com React.
* Praticar aplicações reais.
* Evoluir no desenvolvimento Front-End.
* Construir projetos para portfólio.
